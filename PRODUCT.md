# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

SOC analysts, detection engineers, and security engineering portfolio reviewers.
They investigate local telemetry, trace detections to raw evidence, and evaluate
rules against reproducible positive, benign, and boundary scenarios.

## Product Purpose

SentinelFlow is a locally runnable detection engineering and security analytics
application. Success is a working evidence chain and reproducible measured
validation, not a decorative dashboard.

## Operating Context

A single-user local workstation; SQLite by default; no cloud account or paid
security service. Desktop investigation and mobile review must both be usable.
The default content is explicitly synthetic and uses invented identities and
reserved/private addresses.

## Capabilities and Constraints

Python/FastAPI backend, React/TypeScript frontend, data-driven YAML rules,
normalized telemetry, chronological replay, alert evidence, isolated detection
validation, and an explicitly limited Sigma importer. No full EVTX support.
This portfolio application is not a production SIEM or enterprise coverage claim.

## Brand Commitments

SentinelFlow. Professional SOC tooling: operational scanability, strong
hierarchy, restrained coherent styling, and accessible states. The user
delegated visual choices without additional aesthetic questions.

## Evidence on Hand

The implemented event pipeline, seven YAML detections, authored fixture
expectations, licensed source samples, and actual execution receipts are saved
with the project. The live screenshots and continuous browser recording show
the running application and real backend output. Measurements describe included
scenarios only, not enterprise detection coverage.

## Product Principles

- Evidence is always one step away.
- Expected and observed results must be distinguishable.
- Runs are isolated and their scope is visible.
- Errors are actionable; no success-shaped fallbacks.
- Suspicious indicators are not proof of compromise.

## Accessibility & Inclusion

Keyboard-operable navigation and forms, visible focus, labeled inputs, semantic
tables, textual severity/status, reduced-motion support, and responsive layouts.
